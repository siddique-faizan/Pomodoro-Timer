# Pomodoro Timer

A fully automated Pomodoro productivity timer built 
with Python and Tkinter.

Features:
- Automated work/break cycle (25/5/20 minutes)
- Colour-coded countdown - green > Yellow > orange > red
- Audio notification upon session completion
- Checkmark tracking for completed work sessions
- Configurable sessions before long break
- Proper timer cancellation on reset

Built as part of 100 Days of Code (Day 28).
Extended beyond tutorial with additional features.
